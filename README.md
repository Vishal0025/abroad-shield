# 🛡️ AbroadShield Club

> **Real Feedback from Students Abroad — Don't Fall for Agent Scams**

AbroadShield is a global student community and verification network designed to protect study abroad aspirants from predatory education agents, deceptive work-permit promises, and hidden visa trap colleges.

---

## 🌟 Key Features

- **🏛️ Agent Wall of Truth**: Real reviews and ratings of education agencies submitted by verified students abroad. Automatically links or registers unlisted agencies dynamically.
- **🎓 Verified Senior Mentors**: Connect directly with verified seniors studying in Canada, UK, USA, Germany, Australia, Ireland, France, Netherlands, and Sweden.
  - Chat securely with seniors.
  - Direct WhatsApp quick-contact options for seniors who choose to share their number publicly.
  - Strict privacy protections for seniors who keep their contact private.
- **📸 Profile Management**: Student and senior profiles with custom photo uploads, instant avatar presets, college, course, and campus location tags.
- **🚨 Senior Advisory Alert System**: Live rolling warnings and advisories from seniors abroad about part-time job realities, policy shifts, and agency traps.
- **🤖 Fake Offer Letter & Lie Detector**: AI-powered scam analysis for suspicious visa offers and exorbitant agency fees.
- **💰 Honest Cost of Living Calculator**: Real-world monthly budget breakdown by destination city.
- **🔒 Anti-Agent Security Engine**:
  - Strict anonymous username pseudonyms — real names and student ID cards are never shown publicly.
  - Multi-account device hardware fingerprinting prevents commercial agencies from spamming fake reviews.
  - Admin Confidential Vault (`/admin`) with passkey authorization to safeguard identity proofs.
- **📱 Responsive Mobile Experience**: Fully optimized for iPhone and Android devices with an ergonomic touch navigation drawer and gesture support.

---

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, CSS3 (Modern Glassmorphism & Micro-animations), Vanilla JavaScript (ES6+)
- **Backend / Cloud Database**: Supabase (PostgreSQL with Row-Level Security)
- **Local Fallback**: HTML5 `localStorage` caching for instant offline performance
- **Hosting Ready**: Zero-config deployment on Vercel, Netlify, or GitHub Pages

## 🚀 Quick Start (Local Development)

Clone the repository and start the server:

```bash
git clone https://github.com/Vishal0025/abroad-shield.git
cd abroad-shield
npm start
```

Open your browser and navigate to:
```text
http://localhost:3000
```
